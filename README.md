# chart-alert

5分ごとにチャートを確認して、条件に来たらスマホ（ntfyアプリ）に通知します。

| 銘柄 | 条件 |
|---|---|
| ドル円・原油(WTI)・ゴールド | 5分足ボリンジャー(20, 3σ) %B 0.05以下 / 0.95以上 |
| 日経（先物 NIY=F） | 日足・1時間足 RSI(14) 70以上 / 30以下 |

- 同じ状態のあいだは1回だけ通知します。%Bが0.20/0.80、RSIが35/65まで戻ったら、次の通知の準備ができます。
- 数字を変えるときは `monitor.py` の上のほうの「設定」を書きかえます。

## 準備
1. スマホに ntfy アプリを入れ、決めた名前（トピック）を購読する
2. GitHubの倉庫の Settings → Secrets and variables → Actions で `NTFY_TOPIC` にその名前を入れる
3. Actions → chart-alert → Run workflow でテスト通知を送る
